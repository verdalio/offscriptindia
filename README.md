# offscriptindia

Public source for the r/OffScriptIndia community on reddit: a chill india wide hangout for life off the default script.

subreddit: https://www.reddit.com/r/OffScriptIndia/

what lives here:
- brand/: the community banner and icon
- setup/: the community setup spec (description, rules, flairs, welcome post)
- wiki/: markdown source of the subreddit wiki pages - this repo is the source of truth, the subreddit wiki follows it

## how to contribute

open a pull request or an issue. a maintainer reviews everything before it merges - nothing goes live automatically.
