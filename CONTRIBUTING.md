# contributing

anyone can propose additions or fixes:

1. fork this repo and open a pull request, or open an issue describing the change.
2. a maintainer reviews every proposal before merge. no direct write access for contributors.
3. for wiki changes, edit the markdown under wiki/ here - merged changes get mirrored to the subreddit wiki.

keep proposals grounded: no invented members, meetups, events or claims. if you suggest a rule or flair change, say why in the pr.
